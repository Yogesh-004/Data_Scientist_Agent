# 🧠 Autonomous AI Data Scientist Agent

An intelligent AI-powered system that automates data analysis, visualization, and insights — just like a real data scientist.

---

## 🚀 What This Project Does

This application allows users to upload datasets and interact with them using natural language.

It can:

- 📊 Explore datasets automatically
- 📈 Generate dashboards
- 🔍 Detect anomalies
- 🔮 Perform time-series forecasting
- 🧠 Provide AI-generated insights
- 📡 Sync results with Power BI
- 🧾 Remember past queries (memory)
- 📚 Understand data using RAG (Retrieval-Augmented Generation)

---

## 🧠 Key Features

### 🔹 AI-Powered Analysis
Ask questions like:
> "Show sales by category"  
> "Find trends in profit"  
> "Predict future sales"

---

### 🔹 Smart Dashboard Generation
- Bar charts
- Pie charts
- Line charts
- KPI metrics

---

### 🔹 Anomaly Detection
Automatically identifies:
- Outliers
- Abnormal trends
- Data inconsistencies

---

### 🔹 Time-Series Forecasting
- Detects date columns automatically
- Predicts future values
- Visualizes trends

---

### 🔹 RAG (Retrieval-Augmented Generation)
- Understands column meanings
- Improves AI responses using context

---

### 🔹 Memory System
- Stores past queries
- Improves future responses

---

### 🔹 Multi-Dataset Support
- Upload multiple files
- Analyze combined datasets

---

### 🔹 Power BI Integration
- Sends processed data
- Updates dashboards in real-time
